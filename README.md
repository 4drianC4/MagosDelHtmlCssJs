# 🧙‍♂️ Magos del HTML, CSS y JavaScript

> *"El camino del mago desarrollador comienza con un solo hechizo... un tag HTML"*

Bienvenido a la Academia de Magos del Desarrollo Web, donde aprenderás los antiguos conjuros del HTML, los encantamientos del CSS y los poderosos hechizos de JavaScript.

## ✨ Sobre este Grimorio

Este curso te guiará a través de un viaje mágico de 12 días, transformándote de aprendiz a mago del desarrollo web. A lo largo del camino construirás tu propio **portafolio interactivo**, que presentarás en dos hitos clave (Día 6 y Día 12).

## 📚 El Camino del Mago - Temario

### 🌟 Semana 1: Los Fundamentos Mágicos

**Día 1: Introducción a HTML y estructura básica**
- Los primeros conjuros: etiquetas básicas
- La estructura sagrada de un documento HTML
- Herramientas: VS Code, Emmet y primeros atajos

**Día 2: HTML semántico y estructura avanzada**
- Conjuros semánticos de poder
- Formularios y tablas
- La magia de la accesibilidad (`alt`, `scope`, `label`)

**Día 3: Introducción a CSS y estilos básicos**
- Los encantamientos visuales
- Selectores: eligiendo tu objetivo
- Colores, fuentes y el modelo de caja

**Día 4: CSS intermedio: Diseño y posicionamiento**
- El Flexbox: organización dimensional
- Grid: la cuadrícula de poder
- La cascada y la especificidad

**Día 5: CSS avanzado y responsive design**
- Adaptabilidad mágica: media queries
- Transformaciones, transiciones y animaciones
- Variables CSS y Google Fonts

**Día 6: Presentación del portafolio (HTML/CSS) 🎨**
- Integrar todo lo aprendido en tu primer portafolio
- Guía de presentación y rúbrica de evaluación

### ⚡ Semana 2: La Magia de JavaScript

**Día 7: Introducción a JavaScript**
- El lenguaje de los hechizos dinámicos
- Variables, tipos de datos y operadores
- La consola del navegador y template literals
- (Opcional) Node.js y NPM para los más curiosos

**Día 8: Estructuras de control y funciones**
- Condicionales: caminos que se bifurcan
- Bucles: el poder de la repetición
- Funciones: encapsulando magia reutilizable

**Día 9: Arreglos y objetos**
- Arrays: colecciones de poder
- Objetos: estructuras de conocimiento
- Valores vs referencias y el spread operator

**Día 10: Manipulación del DOM y eventos**
- El árbol sagrado del documento
- Seleccionando y modificando elementos
- Event listeners: los centinelas del código
- (Opcional) Runas de protección: RegEx

**Día 11: Proyecto final - Portafolio interactivo ⚡**
- Modo oscuro, filtro de proyectos, formulario inteligente y menú responsive
- Todo con JavaScript aplicado al portafolio del Día 6

**Día 12: Gran demostración de maestría 🏆**
- Presentación del portafolio interactivo
- Guía de presentación, preguntas y rúbrica final

## 🎯 Objetivos del Curso

Al completar este entrenamiento mágico, serás capaz de:

- ✅ Construir estructuras web sólidas con HTML semántico
- ✅ Dar vida y estilo a tus creaciones con CSS (incluyendo responsive)
- ✅ Crear experiencias interactivas y dinámicas con JavaScript
- ✅ Desarrollar un portafolio web completo desde cero
- ✅ Aplicar las mejores prácticas del desarrollo web moderno

## 🔮 Requisitos Previos

- Computadora con navegador web moderno
- Editor de código (recomendado: VS Code)
- Ganas de aprender y experimentar
- Mente abierta a la magia del código

## 🚀 Cómo Usar Este Grimorio

1. Sigue el orden de los días secuencialmente (Día 1 → Día 12).
2. Practica cada hechizo (concepto) antes de avanzar.
3. Completa los ejercicios y desafíos propuestos al final de cada día.
4. No tengas miedo de experimentar y romper cosas.
5. ¡La práctica constante es la clave de la maestría!

## 📖 Recursos Adicionales
